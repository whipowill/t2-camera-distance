# CameraDistance

A Torchlight 2 mod to standardize camera distance.

In this game the camera distance changes from map to map.  In dungeons it's normally set at the standard value of ``1`` but in towns and open world maps the distance is increased 20%.  This felt like a design flaw and made it difficult to connect with my character bc they are so tiny.  This mod makes all the maps in the game use a camera distance of ``1``.

While you can use the ingame console to set this value (``cameradistance 1``), that won't work on multiplayer games.  This mod fixes it w/out the use of a console command.
